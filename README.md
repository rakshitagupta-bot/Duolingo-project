# 🦉 Duolingo Math for Adults: Closing the Day 1 Gap

**A Product Management Proposal & Interactive Prototype by Rakshita Gupta**

This repository contains a strategic product proposal and a fully coded interactive prototype designed to solve a core retention problem for Duolingo Math: **closing the Day 1 to Day 3 gap for adult learners.**

---

## 🧠 The Problem
Math is one of Duolingo's biggest growth bets, and adults are a primary target audience. However, the window to turn a download into a habit is narrow. Currently, adult learners drop off heavily before Day 3 because the initial onboarding and placement feel abstract, devoid of context, and geared towards children (e.g., "Grade 3 Math").

Motivation doesn't survive a first session that feels like it wasn't made for the user.

## 💡 The Solution
This proposal introduces a 3-step intervention focused entirely on the **first session experience**, requiring no new infrastructure or core lesson engine changes:

1. **Intent Anchoring:** Ask users *why* they are learning (Everyday Life, Work, Kids' Homework, Exams) before they take a placement test.
2. **Adaptive Real-World Placement:** Replace abstract arithmetic with 5 scenario-based questions matched to their chosen intent.
3. **Skill-Level Framing & Real World First:** Replace "Grade Level" results with "Skill Levels" (e.g., Level 3: Percentages), and ensure the very first lesson question reflects their stated real-world goal.

## 🛠️ Tech Stack
This project was built to be lightweight, instantly accessible, and easy to share.
* **HTML5**
* **Vanilla CSS3** (Custom Duolingo-style physics, buttons, and animations)
* **Vanilla JavaScript** (State management for the quiz prototype, confetti animation, and logic routing)
* *Zero dependencies, no build tools required.*
